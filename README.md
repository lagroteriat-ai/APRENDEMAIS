# Aprende+

Landing page do Aprende+ inspirada no layout de referência enviado.

## Arquivos

- `index.html` — estrutura da página
- `style.css` — visual, responsividade e layout
- `script.js` — rolagem suave, ano automático e formulário
- `assets/estudante.jpg` — imagem utilizada na área principal

## Protótipo

O botão de cadastro e os botões de acesso levam ao protótipo:
https://aureaplay-ndghrrkn.manus.space/

## Como abrir

Abra o arquivo `index.html` no navegador ou abra a pasta no VS Code e use uma extensão como Live Server.
